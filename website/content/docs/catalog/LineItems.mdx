description: "Receipt/order lines with qty x name and amount, plus summary lines (subtotal, tax, total). currency is a prefix symbol, default $."
---

## Use it when

A receipt shape: priced rows plus the subtotal, tax, and total that follow from them. This is the one data component that formats money itself, so prefer it over Table whenever amounts add up. Rows that are not amounts, or need more than a name and a number, belong in Table; non-priced fields of the same record belong in KeyValue.

## Prompt hints

- "Show my cart with VAT and the total"
- "Break down this invoice"
- "What did I order yesterday and what did it cost?"

`amount` is a number and LineItems renders it. With `currency` set, that string is used verbatim as a prefix and the number is grouped to two decimals; with `currency: null` the amount falls back to the host formatter from `VexaProvider format`, which defaults to `en-US` / `USD` and prints `$`. `qty` renders as `2×` before the name, `detail` as a small italic line under it, and a summary line with `emphasis: "total"` is the only one set in the primary colour at a larger size.

## Props

> Nullable props are optional from the model's point of view: the model must send `null` explicitly, it cannot omit the key.

| Prop | Type | Required | Description |
| --- | --- | --- | --- |
| `items` | `({ name: string; detail: string \| null; qty: number \| null; amount: number })[]` | Yes | Example: `[{"name":"Latte","detail":"Oat milk","qty":2,"amount":180},{"name":"Croissant","detail":null,"qty":1,"amount":85}]` |
| `summary` | `({ label: string; amount: number; emphasis: "total" \| null })[] \| null` | No | Example: `[{"label":"Subtotal","amount":265,"emphasis":null},{"label":"VAT 7%","amount":18.55,"emphasis":null},{"label":"Total","amount":283.55,"emphasis":"total"}]` |
| `currency` | `string \| null` | No | Example: `"$"` |

## Example spec

```json title="spec.json"
{
  "type": "LineItems",
  "props": {
    "items": [
      {
        "name": "Latte",
        "detail": "Oat milk",
        "qty": 2,
        "amount": 180
      },
      {
        "name": "Croissant",
        "detail": null,
        "qty": 1,
        "amount": 85
      }
    ],
    "summary": [
      {
        "label": "Subtotal",
        "amount": 265,
        "emphasis": null
      },
      {
        "label": "VAT 7%",
        "amount": 18.55,
        "emphasis": null
      },
      {
        "label": "Total",
        "amount": 283.55,
        "emphasis": "total"
      }
    ],
    "currency": "$"
  }
}
```
