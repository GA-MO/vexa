## Goal

A German user should see German everywhere: the empty state and buttons of the panel, the assistant's sentences, and amounts written the way German apps write them (`1.234,56 €`). Three settings cover it, each on the layer that owns the text: `format` and `chat.labels` on the provider, the answer language on the server.

## What the user asks

- "Zeig mir die Rechnung für die letzte Bestellung"
- "Wie lief das Quartal im Vergleich zum Vorjahr?"
- "Wo ist Bestellung #A-1042?"

## How it works

### Numbers and money

`format` takes a `locale` and an ISO currency code. Every component that prints a number (Metric, LineItems, KeyValue, chart axes, `$computed formatCurrency`) reads it from context.

```tsx title="app/providers.tsx"
"use client";

import { VexaProvider } from "vexa/react";
import { VexaChatOverlay } from "vexa/chat";

export function Providers({ children }: { children: React.ReactNode }) {
  return (
    <VexaProvider
      format={{ locale: "de-DE", currency: "EUR" }}
      chat={{
        title: "Acme Assistent",
        subtitle: "Fragen · Antworten · als UI",
        suggestions: [
          { label: "Quartalsumsatz", prompt: "Wie lief das Quartal im Vergleich zum Vorjahr?" },
          { label: "Bestellstatus", prompt: "Wo ist meine letzte Bestellung?" },
        ],
        labels: {
          emptyTitle: "Frag einfach",
          emptyDescription: "Stell eine Frage und bekomm die Antwort als UI",
          thinking: "Denkt nach…",
          approve: "Erlauben",
          reject: "Ablehnen",
          run: "Ausführen",
          cancel: "Abbrechen",
          startOver: "Neu beginnen",
          closeChat: "Chat schließen",
          openAssistant: "Assistent öffnen",
          closeAssistant: "Assistent schließen",
          placeholder: "Stell eine Frage oder lass dir eine UI bauen...",
          send: "Senden",
          selectModel: "Modell wählen",
          steps: (count) => `${count} Schritte`,
          approveTool: (tool) => `${tool} ausführen erlauben?`,
          runOnPage: (tool) => `${tool} auf dieser Seite ausführen?`,
          securityTitle: "Verdächtiger Text in Tool-Daten gefunden",
        },
      }}
    >
      {children}
      <VexaChatOverlay />
    </VexaProvider>
  );
}
```

`labels` is a `Partial<ChatLabels>`: any key you leave out keeps its English default. Function-valued keys (`steps`, `approveTool`, `runOnPage`, `securityBody`, `toolState`) receive the count, tool name, or tool state, so word order is yours. An invalid locale or currency falls back to `en-US` / `USD` with a console warning rather than throwing.

### The assistant's language

The catalog rules already say "respond in the user's language", so a German question gets a German answer without configuration. For a single-language app, fix it on the server so an English question from a German user still gets German:

```ts title="app/api/chat/route.ts"
export const { GET, POST } = createVexaHandler({
  models,
  persona: "Du bist der Assistent von Acme. Antworte immer auf Deutsch, höflich und knapp.",
  instructions: ["Component labels, table headers, and button text must be German. Keep product names and order ids as they are."],
});
```

`persona` is the first prompt layer and `instructions` come after the operational rules; both are host text and neither can override the library invariants that follow them.

### Component text

Component strings such as Table headers and Button labels are written by the model, so the instruction above is what makes them German. The only text the library prints inside a spec is formatted numbers, which `format` handles; the components inherit `font-family` from the page, so a script that needs its own glyphs needs a font on the host page.

## Prompt hints

- Decimal separators: "write Metric values with a comma as the decimal separator (2,4 Mio. €)" keeps the model's strings consistent with the axes the formatter prints.
- Dates and times: "write times as HH:MM and dates as d. MMM (14. Sept.)".
- Mixed audiences: leave `persona` language-neutral and let the catalog rule follow each user.
